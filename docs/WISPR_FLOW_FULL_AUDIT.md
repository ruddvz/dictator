# Wispr Flow full audit, and how Dictator beats it

_2026-11-04. Covers Wispr Flow as documented online (help centre docs.wisprflow.ai, wisprflow.ai/whats-new, pricing page, reviews), plus what can be read from the installed Wispr Flow 1.6.1337 bundle (asset names, easing values, icon library). The user's own Flow install is new and hides features that unlock with use, so screenshots of it are not the reference. Behaviour and proportions only: no Flow assets, copy or code are reused, and no GPL code (FluidVoice, MacParakeet) is to be copied. The raw research notes, with a source link per claim, are in the session notes folder as `wispr-flow-research.md`._

Sources are abbreviated: **HC** = a docs.wisprflow.ai article, **WN** = wisprflow.ai/whats-new, **Bundle** = read from `/Applications/Wispr Flow.app` (v1.6.1337). "(unverified)" means only a third-party source or none.

## Hub spec for the redesign session

Flow 1.6 measurements are in `docs/DESIGN_SYSTEM.md`. What this audit adds:

- **Sidebar.** Width 216, rows 36 on a 40 pitch, icon frame 20 (glyph about 18) and label 15.5 regular; medium when selected, not semibold, so the width doesn't jump. The selected fill is `selection`, with no accent bar. Bottom block: an optional setup or "active meeting" card, then Shortcuts / Help, then Settings. Collapsed rail 68 with tooltips.
- **Lockup.** Flow puts a small mark and wordmark left-aligned under the traffic lights, about 50 pt from the top. Dictator: the ribbon mark in a 32 pt `signalSoft` squircle (radius 9) plus the wordmark at 20 rounded semibold, tracking −0.4. The mark opens into its lens while dictating.
- **Toolbar.** Height 44 to 45, level with the traffic lights; the sheet starts below it. Icon buttons 28–30 square with radius 8. The avatar is a 28 circle (initials in `signal` on `signalSoft`). The strip must drag the window (hidden title bar), and a double-click zooms.
- **History row.** Time column 82 + 16; text 16 on a 20 line, 3 lines then expand. Hover actions sit in a small floating capsule (`sheet`, hairline, faint shadow) at the top right, fading in over 0.12 s and sliding 4–6 pt.
- **Popovers** (notifications 360 wide, profile 300): `sheet` background, 16 padding, rows 32 high with `hover` fill. Each popover sets its own `preferredColorScheme`, since it is a separate window.
- **Empty states.** Flow uses illustrations (no notifications, notetaker empty, coachmarks). Dictator: a calm ribbon drawing in `ink3` rather than characters, in keeping with "hush".

## What competitors do better than Flow, and what Dictator takes

| App | Better than Flow at | Take for Dictator |
| --- | --- | --- |
| **FluidVoice** (GPL, macOS 15+) | Local models (Parakeet, Whisper, Apple Speech), a **live preview** of words as you speak, notch-aware overlay, hold-Space-to-mute, a today-usage pill in the toolbar, a compact theme switch | A live partial transcript in the toolbar chip or pill (optional); today's words in the profile popover. Ideas only, no code. |
| **MacParakeet** (GPL) | File and URL transcription, speaker diarisation, eight export formats, a deterministic **Raw vs Clean** pipeline that keeps both texts, audio retention choices, dictation stats with top apps | Raw / Clean / Polished levels; keep raw and clean (Dictator already stores `rawText`); retention ladder; a "top apps" tile in Insights |
| **Superwhisper** | Offline models, **named modes** with per-app auto-switch and a mode chip in the recording window, a mini window, a cancel confirmation only for recordings over 30 s, lifetime pricing | Show the active app profile or mode in the toolbar chip; confirm cancel only after 30 s |
| **Aqua Voice** | Technical-vocabulary accuracy, Deep Context, MCP/CLI/API on the free tier, playful rewards | A local CLI or Shortcuts actions later; playful but quiet milestone moments |
| **Willow** | Speed claim (~200 ms), style memory per app, optional offline mode, mid-dictation language switching | Show measured latency per dictation in history meta ("typed in 0.4 s"). Dictator is local, so this is a claim it can prove. |

Flow's real moats are cross-platform sync, audited compliance, team admin, and the Notetaker + Ask + MCP bundle. Dictator shouldn't chase those. It wins on: everything on this Mac, no account or caps, whispers and silent speech, file transcription, and a cleanup that never rewords.

## Top hub gaps, in order

1. Toolbar chrome: theme, bell, profile, sidebar toggle, live chip.
2. Custom icon set and motion tokens (`glide`, hover 0.12 s, sliding selection, stagger).
3. History rows: floating hover pill, Copy → check, ⋯ menu, expand, meta line.
4. Sidebar: 15.5 / 20 sizes, left lockup, collapse to rail, Shortcuts above Settings.
5. Home stats card: voice profile + time saved.
6. Settings: split General; shortcut recorder; notification categories.
7. First-run onboarding with the practice field and whisper test.
