## Build, package, and test

```bash
# 1. Run unit tests
xcodegen generate
xcodebuild -project Dictator.xcodeproj -scheme Dictator -derivedDataPath .build CODE_SIGNING_ALLOWED=NO test

# 2. Package with stable local code signing (MANDATORY for macOS TCC Accessibility trust)
./Scripts/package-app.sh

# 3. Deploy and launch the signed app
killall Dictator 2>/dev/null || true
rm -rf /Applications/Dictator.app && cp -R dist/Dictator.app /Applications/Dictator.app
open /Applications/Dictator.app
```

> **CRITICAL RULE FOR ALL AGENTS:** NEVER run raw ad-hoc or unsigned builds from `.build/Build/Products/...`. macOS Sequoia/Sonoma ties Accessibility trust to the designated requirement of the `Dictator Local Signing` certificate. Opening an ad-hoc build revokes system Accessibility permissions and breaks insertion into all apps. Always package with `./Scripts/package-app.sh`.

Only one Dictator should run at a time; quit any running instance before launching an update.

## Text insertion rules (DO NOT REVERT)

1. **Chromium/Electron AX behavior:** When setting `kAXSelectedTextAttribute` on web inputs in Chromium/Electron (Codex, Antigravity, VS Code, Slack, Chrome), macOS returns `.success` but the web DOM remains `.unchanged`. Direct AX verification returning `.unchanged` MUST NOT assert `requiresReviewAfterInsertion = true` — it must cleanly fall through to ⌘V paste.
2. **Clipboard hygiene:** NEVER add `org.nspasteboard.ConcealedType` or `com.agilebits.onepassword` to `ClipboardSnapshot.transientTypes`. Web security layers in Chromium/WebKit treat concealed items as passwords and block web text boxes from reading the clipboard. Only standard transient types (`TransientType`, `AutoGeneratedType`, `de.petermaurer.TransientPasteboardType`) are allowed.
3. **Clipboard restore delay:** `unverifiedPasteRestoreDelay` must be at least 2.5s (2500ms). Electron's multi-process IPC takes up to 800ms; wiping the clipboard in 500ms causes empty pastes in web apps.
4. **Keystroke synthesis:** Synthesize ⌘V with `vDown` and `vUp` (`kVK_ANSI_V`) with `.maskCommand` to `.cghidEventTap` and a 35ms dwell time. NEVER emit `kVK_Command` (virtual key 55) as a `keyDown` event (it corrupts Electron's event pump).
